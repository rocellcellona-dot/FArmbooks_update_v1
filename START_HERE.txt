FARMBOOKS MOBILE — START HERE

1. Extract this ZIP.
2. Open the FarmBooks-Mobile-Project folder in VS Code (the folder containing package.json).
3. Configure Firebase in firebase.js by replacing the YOUR_... placeholder values with your Firebase Web App configuration.
4. Enable Firebase Authentication Email/Password.
5. Create Firestore Database and publish the reviewed firestore.rules file.
6. Optional: create Firebase Storage, configure storageBucket, then publish storage.rules for photo upload.
7. In VS Code Terminal, run:
   npm install
   npx expo-doctor
   npx expo start --clear
8. Scan the terminal QR code with Expo Go.
